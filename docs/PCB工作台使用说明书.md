# PCB 工作台使用说明书

PCB 工作台用于在嘉立创 EDA 中记录板上事项、跟进处理进度和整理交接资料。便签可以关联元件或焊盘，也可以记录整板安排；交接包保留正文、原文和图片，解压后即可阅读。

适用版本：v0.9.7 · 嘉立创 EDA 专业版

[版本更新](../CHANGELOG.md) · [安装部署](部署与依赖.md)

## 开始使用

### 安装插件

1. 在嘉立创 EDA 中打开 **高级 → 扩展管理器**。
2. 导入下载的 `.eext` 扩展包。
3. 确认 **PCB 工作台** 已启用，并开启 **允许外部交互**。
4. 确认配套服务已启动，打开要记录的 PCB。

首次部署请参阅 [安装部署](部署与依赖.md)。已经安装的用户可直接开始记录。

### 记下第一条便签

1. 在 PCB 中选中要记录的元件或焊盘。
2. 打开 **高级 → PCB 工作台 → PCB 随手记**。
3. 首次打开时，点击 **为当前工程新建便签本**。
4. 点击 **新建便签**，填写标题和正文。标题可以留空。
5. 点击 **保存**，或在正文编辑区按 **Ctrl+Enter**。

保存后，左侧列表会出现这条便签。点击 **返回 PCB** 继续工作，之后可从同一入口再次打开。

没有选中对象时，也可以新建便签，用来记录整板事项。

### 把记录交给别人

在列表勾选便签，点击 **按原文导出**，核对段落和图片后点击 **按原文生成**。检查正文，再点击 **确认范围并导出** 保存 ZIP。

接收方解压后打开 **阅读说明.html**，即可查看文字、原文和附图。

## 认识工作台

打开 PCB 后，从 **高级 → PCB 工作台** 进入。

| 入口 | 用途 |
| --- | --- |
| PCB 随手记 | 记录事项、关联元件与焊盘、追加进展、保存图片、整理文字和制作交接包 |
| PCB 设计检查 | 查看原生 DRC 问题、生成中文解释、选择关联对象、重新检查并比较结果 |
| 采集当前 PCB | 读取并保存当前 PCB 的结构化信息 |

日常记录主要使用“PCB 随手记”。保存便签、查找记录和按原文导出不需要调用文字整理服务。

### 面板分区

| 位置 | 可以做什么 |
| --- | --- |
| 顶部 | 查看当前工程与文档、切换整理服务、刷新、返回 PCB |
| 左侧列表 | 新建、搜索和筛选便签，勾选交接范围 |
| 右侧内容 | 编辑正文、查看进展、添加图片、对照草稿 |
| 左下方整理进度 | 查看正在处理或已完成的任务 |

### 记录如何组织

一个便签本保存工程中的多条便签。每条便签包含初始记录，可继续追加进展。交接时既能选择整条便签，也能在预览中取消某段进展或某张图片。

## 记录与追加进展

### 写清当前事项

一条便签记一件事。标题用于查找，正文写当前观察、决定或待办。正文不能为空，填写后点击 **保存**。

例如，核对两处元件规格时可以这样记录：

> C1 名称为 4.7uF 35V，C2 为 4.7uF 100V。先分别核对原理图和物料表，当前保留原有名称。

### 追加进展

打开已有便签，点击“追加进展”，填写新情况后保存。初始记录与各段进展分别保留，适合补充资料、记录处理结果和更正之前的说明。

需要修改某段时，点击该段下方的“编辑此条”。修改后保存，旧文字保留在历史版本中，可在“更多”区域查看。

### 恢复输入

离开前先确认已保存。重新打开时若出现“恢复编辑”或“恢复未保存的草稿”，可以恢复内容，检查后再次保存。恢复副本保持原来的工程归属。

## 关联板上对象

| 类型 | 创建方式 |
| --- | --- |
| 元件便签 | 在 PCB 选中元件，再新建便签 |
| 焊盘便签 | 选中实际焊盘，再新建便签 |
| 多对象便签 | 同时选中多个受支持对象，再新建便签 |
| 整板便签 | 未选择具体对象时新建 |

“整板便签”适合记录工程来源、资料清单或交接安排，不要求关联某个器件。

### 为已有便签关联对象

1. 保存编辑内容，返回 PCB。
2. 在板上选中需要关联的元件或焊盘。
3. 打开对应便签，展开“更多”。
4. 点击“关联当前选中对象”。

关联会更新为当前选中的对象集合，正文、进展和旧关联历史仍保留。工程与文档必须一致，插件不会根据标题里的位号自动猜测对象。关联后若左侧标签尚未更新，点击顶部 **刷新**。

### 在板上选择

有关联对象的便签会显示“在板上选择”。点击后，插件清除旧选区，再选中记录关联的对象。点击“返回 PCB”查看画布。

对象被删除、标识变化或工程不一致时，按提示重新核对。关联历史便签本只恢复记录，不会自动重新绑定所有对象。

## 添加图片

1. 打开要附图的记录或进展。
2. 点击 **选择文件**，选择 PNG 或 JPEG 图片，也可直接粘贴剪贴板中的图片。
3. 填写图片说明，例如“C2 名称与封装属性”。
4. 点击 **保存**。

重新打开记录即可查看附图。修改说明会保留旧版本；移除图片时，点击 **移除此条附件**，再保存记录。

文字整理使用图片说明，不识别图片中的文字或电路。交接时可单独选择需要带出的图片。

## 整理文字

1. 保存需要整理的记录。
2. 点击“整理文字”。
3. 可以继续记其他事项，或返回 PCB。
4. 展开左下角“整理进度”，完成后点击“查看草稿”。
5. 对照原文，合适时点击“采用这版”。

结果不会自动覆盖记录。采用后显示“已采用”，原文仍在历史版本中。原文已经清楚时，结果可能保持原样。

提交后又修改了记录，旧草稿会提示来源变化，不能直接覆盖新内容。可以重新整理，或复制所需文字后手动编辑。

任务可“取消”，失败后可“重试原版本”。重试沿用原来的来源版本和服务配置；想换服务或改用最新文字，应重新提交。

关闭面板后，整理任务可以继续运行。使用期间保持配套服务运行；电脑关机或休眠后，重新打开时先查看任务状态。

### 查看整理状态

| 状态或提示 | 下一步 |
| --- | --- |
| 排队或正在整理 | 可以继续记其他事项，稍后在整理进度中查看 |
| 查看草稿 | 打开结果，对照原文再决定是否采用 |
| 已采用 | 整理稿已保存到对应记录 |
| 来源有变化 | 查看新记录，或重新整理 |
| 整理失败 | 检查服务连接，再重试原版本或按原文导出 |

## 制作交接包

### 选择范围

1. 在列表勾选需要交接的便签。
2. 点击“整理交接”。
3. 在范围预览中逐项核对记录、进展和图片，取消不需要的内容。
4. 可填写交接目的，也可留空。
5. 点击“整理所选记录”。

同一便签可以包含多段进展，实际交接范围以预览中的段落为准。

### 编辑与更新

打开完成后的草稿，可修改正文、填写补充事项，再点击“保存修改”。正文保留对应原文入口，便于检查位号、参数和进度。

有“待补充”问题时，可以保留，也可以勾选“导出时不附这些问题”。

来源后来更新时，可“重新核对来源”，或“用当前来源重新生成”。旧稿继续保留。如果需要改变段落或附件范围，回到列表重新选择。

### 保存交接包

整理稿检查后可直接导出。希望保留原文时，勾选便签，点击“按原文导出”，核对范围后点击“按原文生成”。

两种路径均可选择：

- **确认范围并导出**：导出已核对版本。
- **导出未确认草稿**：保留草稿状态。
- **仅导出文字，不包含图片**：生成纯文字包。

导出会发起 ZIP 保存。在系统保存窗口选择位置，完成后检查文件已落盘。来源已有更新时，导出旧稿需要确认使用预览中的历史版本。

### 离线阅读

解压整个 ZIP，双击 **阅读说明.html** 即可离线阅读，不需要启动插件或配套服务。正文下方的原文入口可跳转到来源记录，附图区包含图片和说明。

| 文件 | 内容 |
| --- | --- |
| `阅读说明.html` | 交接正文、原文入口与图片 |
| `交接报告.md` | Markdown 交接正文 |
| `原始记录.md` | 本次范围内的来源文字 |
| `attachments/` | 导出的图片；纯文字包不含图片 |

移动或转交时保留完整解压目录，不要只拷贝 HTML。停止分享后，涉及该范围的旧包不能再次从服务下载；已保存的副本不受本机服务控制。

## 查找与管理记录

| 操作 | 方法 |
| --- | --- |
| 搜索 | 输入标题、正文、进展关键词或对象标签 |
| 状态筛选 | 选择“待确认”“已处理”或“已归档” |
| 修改状态 | 在“更多”中标为已处理，或改回待确认 |
| 归档与恢复 | 点击“归档记录”；之后从已归档列表恢复 |
| 停止或恢复分享 | 在“更多”中切换；停止分享后不再进入新的交接范围 |
| 历史便签本 | 点击“历史便签本”，选择并确认要关联的记录集合 |

归档保留内容，停止分享控制交接范围，两者用途不同。工程重新导入后名称即使相同，也需要确认便签本归属。

### 切换工程

打开另一个工程后，先核对面板顶部的工程和文档名称。重新导入的工程需要从 **历史便签本** 确认关联。关联记录后，如需更新板上对象，按 [关联板上对象](#关联板上对象) 操作。

## 选择整理服务

在面板右上角展开“设置”，选择“本机服务”或“DeepSeek”，点击“检查连接”查看状态。默认使用本机服务。

可使用的整理服务由安装维护人员预先配置。日常只需在界面中选择服务并检查连接。

首次在便签本中使用 DeepSeek 时会确认发送范围：所选文字、必要对象标识和选中的图片说明。图片文件、整板及其他便签不发送。

切换服务不改变已经提交的任务。失败时不会自动换服务；可以手动重试、切换后重新提交，或按原文导出。取消不能撤回已经发送给服务商的内容。

## PCB 设计检查

### 检查当前 PCB

1. 打开 **高级 → PCB 工作台 → PCB 设计检查**。
2. 点击 **开始分析**。
3. 在问题列表中查看设计规则检查结果、相关解释和建议。
4. 按网络或分页查看问题，需要时选择关联对象回到板上检查。
5. 点击 **导出报告** 保存本次结果。

### 继续检查与复查

| 按钮 | 用途 |
| --- | --- |
| 开始分析 | 采集当前 PCB 和原生 DRC，生成检查解释 |
| 取消 | 取消后续分析；正在执行的原生采集可能需等待返回 |
| 重新检查 | 重新采集、检查，并与上一份同文档结果比较 |
| 重新分析 | 对已保存快照重新生成解释 |
| 导出报告 | 保存当前报告 |

问题列表支持分页、按网络查看，并可选择关联对象。便签设置中的整理服务选项用于便签文字和交接稿，设计检查单独使用已配置的服务。

### 采集板信息

从工作台菜单点击 **采集当前 PCB**，读取板框、图层、元件、焊盘、网络、孔、过孔和原生 DRC 等已支持信息，并保存结构化文件。具体覆盖情况以生成文件为准。

## 常见问题

### 看不到便签怎么办

先确认面板顶部的工程和文档，再打开 **历史便签本** 查找。若是更换电脑或服务后出现，联系安装维护人员确认原有数据是否已迁移。

### 为什么显示整板便签

创建时没有选中具体元件或焊盘。这类记录可以直接使用；需要关联时，先在 PCB 选中对象，再打开便签的 **更多 → 关联当前选中对象**。

### 为什么旧草稿不能直接采用

提交整理后，原记录又被修改。旧草稿对应之前的文字，可以复制需要的部分手动合并，也可以根据当前记录重新整理。

### 关闭面板会丢失任务吗

配套服务保持运行时，任务可以继续处理。重新打开后，在 **整理进度** 中查看结果。未保存的输入需要先保存；发现恢复副本时，可恢复后继续编辑。

### 不想把某条记录交出去怎么办

在便签的 **更多** 中点击 **停止分享**，或在交接预览中取消相应段落和附件。已经下载的交接包需要由持有人自行处理。

### 对方需要安装插件吗

不需要。发送完整 ZIP，对方解压后双击 **阅读说明.html** 即可离线阅读。图片和原文随包保存。

### 其他问题

| 情况 | 处理方式 |
| --- | --- |
| 连接失败 | 确认配套服务已启动、扩展允许外部交互，再检查连接 |
| 关联后左侧标签未更新 | 点击顶部 **刷新** |
| 在板上选择失败 | 确认工程与对象是否变化，必要时重新关联 |
| 提示内容已被更新 | 保留当前输入，重新读取最新记录后合并修改 |
| 整理失败 | 检查连接和任务提示，重试原版本或按原文导出 |
| 图片缺失或损坏 | 恢复附件，或选择纯文字导出 |

问题仍未解决时，提供操作步骤、界面提示和插件版本，便于定位。

## 容量限制

| 项目 | 上限 |
| --- | --- |
| 便签标题 | 200 字符 |
| 每段正文或进展 | 12,000 字符 |
| 每段记录的附件 | 12 张 |
| 单张图片 | 6 MB、2,000 万像素；PNG/JPEG |
| 图片说明 | 2,000 字符 |
| 单次交接 | 40 段记录、30 张附件 |
| 交接目的 | 1,000 字符 |
| 单条便签关联对象 | 100 个 |

记录较多时按事项分批交接，初始记录与进展都计入段落数。

# 部署与依赖

适用版本：v0.9.7。日常操作见 [使用说明书](PCB工作台使用说明书.md)。扩展需要配套本机服务；后端 ZIP 包含源码和依赖清单，不是免依赖程序。

## 安装服务

解压 `pcb-workbench-backend-v0.9.7.zip` 到独立目录。使用 Windows x86-64 和 Python 3.12，以下命令在解压后的根目录执行：

```powershell
py -3.12 -m venv backend/.venv
backend/.venv/Scripts/python.exe -m pip install -r backend/requirements-lock-windows-py312.txt
backend/.venv/Scripts/python.exe -m pip check
```

固定清单包含运行与开发依赖。安装需要联网下载 Python 包，不包含虚拟环境。普通用户导入已经构建的 `.eext`，无需安装 Node。

## 首次启动

```powershell
backend/.venv/Scripts/python.exe scripts/start_backend.py
```

启动器按自身位置找到后端，只监听 `127.0.0.1:8000`，单 worker。健康检查地址为 `http://127.0.0.1:8000/health`。不配置模型即可使用记录、搜索和原文交接。

## 可选文字整理

复制 `backend/.env.example` 为 `backend/.env`，已有文件不要覆盖。

| 配置 | 用途 |
| --- | --- |
| LLM_BASE_URL | 本机或自有模型服务的兼容接口地址；设计检查要求以 /v1 结尾 |
| LLM_API_KEY | 该服务要求的凭据，仅存后端 |
| MODEL_NAME | 服务实际提供的模型 ID |
| NOTES_DEFAULT_PROVIDER | 默认 local，不静默切换 |
| DEEPSEEK_BASE_URL | 保持 https://api.deepseek.com |
| DEEPSEEK_API_KEY | 用户自己的厂商 API 凭据 |
| DEEPSEEK_MODEL | 按厂商 /models 返回填写可用 ID |
| NOTES_DATA_DIRECTORY | 可选独立便签数据目录 |

DeepSeek 接收明确所选文字、必要对象标识和所选图片说明，不发送图片字节、整板及未选便签。设计检查是辅助功能，使用本机模型配置，并在第一次知识检索时从 Hugging Face 下载 BGE 模型；记录和原文交接不触发这个下载。

## 备份与升级

停止服务后备份完整 `output/notes` 或自定义 NOTES_DATA_DIRECTORY，包括附件和历史。另行妥善备份自己的 `.env`。新包解压到新目录，恢复配置并指向原数据目录，不覆盖或删除旧数据。只运行一个便签服务进程。

默认数据目录相对于服务包根目录，与启动终端所在目录无关。已有 API 请求监听在 8000 时，先确认是本项目服务并在其终端停止；不要结束其他 Python 进程。
